# Tariq Hanif — SEO Specialist Portfolio

A responsive, single-page professional portfolio website created from the information in Tariq Hanif's supplied CV.

## Files

- `index.html` — landing page content and sections
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation and footer year
- `assets/Tariq-Hanif-CV.docx` — CV download used by the Download CV buttons

## Run locally

Open `index.html` in a web browser. An internet connection is used for the Google Fonts; the rest of the page is static.

## Publish with GitHub Pages

1. Create a GitHub repository named `tariq-seo-portfolio` (or another name you prefer).
2. Upload the files and folders in this project. Keep `index.html` at the repository root.
3. Commit the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment source, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Wait for the deployment to finish. GitHub will show the published site URL in Settings → Pages.

## Git workflow example

```bash
git init
git add .
git commit -m "Initial SEO portfolio landing page"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/tariq-seo-portfolio.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
